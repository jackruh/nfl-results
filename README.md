# NFL Picker Beta: paper results

Public, timestamped record of paper picks from the NFL Picker Beta price rule. Every pick is committed here before kickoff; the commit history is the proof of when it was posted.

- Site: GitHub Pages, served from this repository's root.
- Data: `data/picks.csv` (every pick, graded against Pinnacle's closing line after its game) and `data/backtest.csv` (historical test of the same rule).
- Status: paper only. Nothing is staked until the rule passes its pre-declared gate.

For information only. Not betting advice.
